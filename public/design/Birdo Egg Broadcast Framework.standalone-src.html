Broadcast Design Framework
Birdo Egg — Slice 2026

The tournament broadcast package for the Slice 2026 livestream. Every graphic derives from a single idea: the Birdo Egg Trail — the rainbow left behind by the pink Birdo egg. This document defines the tokens, gradients, geometry and type that make an element belong to the package, then gives rules so new elements can be generated on-brand without a reference.

v1 · canvas 1920×1080 · units in px, no grid-snapping
01

The Trail — signature gradient

The hero gradient runs lime → hot-pink → cyan, pink pinned to the exact centre (50.15%). It is the identity of the package: every full-frame element wears it. Angle changes with the element's proportions, the three stops never do.

Geometry & depth

06

Building new elements

Any new graphic — bracket, poll, sponsor bug, stat card, transition — is on-brand if it follows these six rules.

RULE 01 · SURFACE
Wear the trail
Full-screen elements use the lime→pink→cyan trail; bars & panels use the warm gold→pink→mauve variant so white type reads. Pink always sits at ~50%. Rotate the angle to suit the shape, never the stops.
RULE 02 · SHAPE
20px everything
Fixed 20px corner radius and, on full frames, a 20px gradient border cutout. Radius is constant — it does not scale with the element.
RULE 03 · TYPE
Inter, white, two weights
Black 900 for the primary line, Semi Bold 600 for support. White only. Broadcast-scale — 72/48 on 1080p, never below 24px.
RULE 04 · CONTENT WELLS
White @ 16% for interiors
Data cells, avatars and slots sit in rgba(255,255,255,.16) wells with 14px radius on top of the gradient — keeps panels legible without a second color.
RULE 05 · DEPTH
Glow the live layer
The active feed/game window lifts with 0 0 37.5px rgba(0,0,0,.57). Overlays stay flat — only one glowing layer per screen.
RULE 06 · THE MARK
Egg anchors, top-left
The pink Birdo egg is the identity mark — white body, magenta outline & spots. Anchor it top-left of nameplates; keep clear space equal to the egg's spot size around it.
Scaling pattern — step & repeat
Multi-item elements (caster rows, brackets, standings) grow by repeating one unit rather than stretching. The commentator bug proves it: 1-up = 650px, each added caster tacks on its own stepped bar. Apply the same to any list-like graphic you build.
