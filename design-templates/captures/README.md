# DOM captures — read this before you edit one

These are **not** theme templates. Everything else in `design-templates/` is
generated by `scripts/figma-template.py` and **compiles back** into an
installable design package. These two do not, and cannot.

| | `../*.template.svg` | `captures/*.capture.svg` |
|---|---|---|
| Source of truth | the shipped theme SVG | one live render, at one moment |
| Generated by | `scripts/figma-template.py` | `scripts/dom-to-svg.js` in the page |
| Edit → back into PRSH | yes, via `scripts/compile-theme.py` | **no** — an edit returns as a code change |

The two post-game callouts (Character Spotlight, Game Summary) draw their
layout in HTML and CSS — 89 flex and 10 grid declarations between them — not
from a theme file. Only the **backdrop** (`callout.svg`) is themable today, and
it is exported as a normal template alongside the others. So a capture is the
only way to get their actual composition into Figma, and it is a photograph:
useful to design *against*, impossible to install.

## What to use them for

1. **Designing the callouts' next look.** Everything is real vectors and real
   text at true 1920×1080 coordinates, so you can restyle in place.
2. **As the starting geometry for a slot contract.** If the callouts are ever
   converted to SVG-driven rendering (the Scorecard is the proof it works —
   1920×1080, 115 slots, toggleable groups), the file you design here becomes
   the basis of `spotlight.svg` / `summary.svg`, not throwaway work.

## What did not survive, and why

The capture reports each of these rather than silently dropping it:

- **Masks and clip-paths.** Both backdrops mask a big team-logo wash down to a
  ghost. Without the mask it comes through at full strength, so the logo behind
  each captain reads far brighter here than on air. Re-mask it in Figma.
- **The AB Theater** (Character Spotlight) is a live three.js camera. A WebGL
  canvas cannot be read back after compositing, so it is drawn as a labelled
  dashed footprint. It is not themable and never will be — treat that rectangle
  as a fixed hole in the layout.
- **`mix-blend-mode: screen`** on the Spotlight's flash layer.
- **All motion.** The reveal is a 5.7-second GSAP timeline across 40 tweens; the
  capture is taken with every timeline forced to its end state, which is what
  the element looks like at rest.

## Fonts

Text is captured as real `<text>` bound to **Inter** and **Chivo Mono**. Figma
ships Inter; add Chivo Mono (Google Fonts) or the numerals will substitute.

## Regenerating

Boot an isolated instance, load the layout with `?sample=1`, force the reveal
timelines to their end, then inject `scripts/dom-to-svg.js` and POST the result
to `scripts/capture-receiver.py`. **Capture at the end state** — at t=0 the
whole layout sits at `opacity: 0`, and a capture taken then is a blank canvas
that looks like a broken exporter rather than an un-run animation.
